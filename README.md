
# TECH-LightBox: English
  (Text, Link, SVG, Video, Table, List, Graphic, Carousel, Image and Audio)<br/><br/>
  Lightbox is an innovative app that offers an integrated experience for viewing and interacting with text, graphic, links, carousel, list, SVG, images, Table, audio, and videos in an intuitive and modern way. With a clean and responsive interface, the app allows users to explore multimedia content efficiently, providing fluid and engaging navigation.

# TECH-LightBox: Português
  (Texto, Link, SVG, Vídeo, Lista, Tabela, Carrossel, Gráfico, Imagem e Áudio)<br/><br/>
  Lightbox é inovador que oferece uma experiência integrada para visualizar e interagir com textos, gráfico, links, carrossel, lista, SVG, imagens, Tabela, áudios e vídeos de forma intuitiva e moderna. Com uma interface limpa e responsiva, o aplicativo permite aos usuários explorar conteúdos multimídia de maneira eficiente, proporcionando uma navegação fluida e envolvente.
