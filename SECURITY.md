# Política de Segurança / Security Policy

🇧🇷 **Português** | 🇺🇸 **English**

---

## 🇧🇷 Português

### Como Reportar uma Vulnerabilidade

Se você encontrar qualquer falha ou problema de segurança neste projeto, **não abra uma Issue pública**. 

Por favor, utilize a aba **Security** deste repositório (opção *Report a vulnerability*) para enviar os detalhes de forma privada. Analisaremos e corrigiremos o problema o mais rápido possível.

---

## 🇺🇸 English

### Reporting a Vulnerability

If you discover any security issue or vulnerability in this project, **please do not open a public Issue**.

Instead, please use the **Security** tab of this repository (*Report a vulnerability*) to send the details privately. We will review and fix the issue as soon as possible.
