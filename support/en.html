Frequently Asked Questions (FAQ)

Where can I install Lightbox?
On absolutely any live web page or CMS platform (WordPress, raw HTML, Wix, Shopify, etc.). Simply reference our library layout as detailed in the technical documentation.
Will the application break my site's default style layout?
No. Lightbox uses strict structural encapsulation. It validates existing DOM components beforehand to shield your page styles from external style interference.
Does the free version license expire?
No, Lightbox is and always will be completely free to run. The commercial activation key exists purely to clear out visual product watermarks.
How does Token activation work?
Once purchased, you will receive a specific license key. Paste it directly into your setup configuration or initialization script to clear the watermark branding instantly.
How many sites can I cover with a single token?
Each standard activation token is locked to a single domain name (URL). If you require bulk licenses for multiple websites, contact our sales desk.
Does Lightbox slow down my page performance?
Not at all. The script package is ultra-lightweight, asynchronous, and designed to load on-demand without blocking native asset rendering pathways.
